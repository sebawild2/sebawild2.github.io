Suffix Tree from Suffix Array and LCP Array

The leaf array L[0..n] gives the leaves of the suffix tree from left to right, and LCP[r] is the string depth of the lowest common ancestor of leaves r−1 and r. One left-to-right sweep with a stack — the right spine of the tree built so far — therefore rebuilds the whole tree. Nodes sit at their string depth, so the picture is the LCP-interval picture.

Format. Either a text, in which case suffix array and LCP array are
            computed for you:

            
text: bananaban$

            
or the two arrays directly, to run the sweep on any Cartesian-tree input:

            
text: bananaban$
L: 9 5 7 3 1 6 0 8 4 2
LCP: 0 1 2 3 0 3 0 1 2

            

            LCP lists LCP[1..n] (n values, no entry for rank 0). Use _
            for a blank in the text. The text is only used for the labels; the sweep reads
            L and LCP.
