Shortest paths as dynamic programming

Every nontrivial shortest path has a last edge — but guessing it makes the subproblems depend on each other cyclically. The cure is a second index: δ≤ℓ(s,w), the cheapest s-w-walk using at most ℓ edges. Now every subproblem depends only on layer ℓ−1, so the dependency graph is a DAG — the cycles of G have been unrolled into a helix. The grid below is that layered graph: row ℓ, column w holds δ≤ℓ(s,w), and every edge vw of G appears once per layer, from (ℓ−1,v) to (ℓ,w).

The same computation, done in place. One dist array instead of n+1 layers, and edges scanned forwards out of each vertex rather than backwards into it. The subproblems (ℓ,v) are then no longer solved exactly — after pass ℓ, dist[w] can already be better than δ≤ℓ(s,w), because an update earlier in the same pass may already have helped. That is harmless: it is never worse, and after n−1 passes it is exact. Switch on the comparison below to watch it run ahead.

Extension: reporting the cycle, not just detecting it
The pseudocode of the lecture stops at HAS_NEGATIVE_CYCLE. Two more passes turn that verdict into a witness, and neither costs more than O(n+m): pred already points backwards along edges that were improved, so walking it from the improving vertex must eventually re-enter a vertex it has seen — and it can only cycle inside a negative cycle. Everything reachable from that cycle then has no shortest path at all, since one more lap is always cheaper. This is what the page draws in blue; it is not part of the algorithm you were asked to know.
Input
The augmented algs4 format, exactly as the graph editor writes it: V on the first line, E on the second, then E lines v w weight (a missing weight defaults to 1), then optionally V lines x y giving the vertex coordinates. Any coordinate scale works — they are re-centred and scaled to fit. Edges are read as directed, v → w.

Files dropped into a graphs/ folder next to this page appear in the menu above, via graphs/index.json or plain directory listing — the same convention as the other pages. At most 12 vertices, or the layer grid stops being readable.
