FM Index

Counting, locating and reading a text using only its Burrows–Wheeler transform B, the character counts O[c] and a few samples. All occurrences of a pattern form an interval of sorted rotations; backward search finds that interval one character at a time, from the last character of the pattern to the first, with two σ-rank operations per character.

  Input format
  

    
One item per line; lines starting with # are comments.


bananaban        the text T; $ is appended (it must not occur elsewhere)
ana              patterns, one per line — the first one is loaded
ba
t=3              optional: sample rate for the suffix array and its inverse
extract=4,3      optional: Extract shows T[4..4+3)

    
Type _ for a space (drawn as ␣). The end-of-word character $ is the smallest
      character; all others are ordered by their character code. Without a t= line, t = ⌊lg(n+1)⌋.

    
Long texts. Every rotation is drawn as a row, so the drawing grows with the text. The slider above the
      rotations squeezes each row after its first few columns (the pattern plus one character, or three columns); B and F
      always keep full width. Below 5 px the squeezed part is drawn as a plain band.

    
Mouse only. The pattern buttons switch patterns; dragging across the drawn text T searches for the
      selected substring (in Extract: selects the range to decode). The slider t changes the sampling.
      Clicking a phase below the progress bar jumps to its first step. On wide screens, the bar between the drawing
      and the pseudocode can be dragged to resize both (double-click resets it).

    
Conventions, as in the pseudocode: T = T[0..n] with T[n] = $, so there are n+1 rows;
      intervals of rows are half-open, [s..e) = {s, …, e−1}. In the drawing, the fence s is solid and the row
      below it belongs to the interval; the fence e is dashed and the row below it does not.
