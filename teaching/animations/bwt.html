Burrows–Wheeler Transform

A reversible permutation of the text — it compresses nothing by itself. Sorting the cyclic shifts groups each character together with the characters that share its following context, so a text whose symbols are predictable from context turns into a B with locally low entropy. MTF then turns locally low into globally low, and only the last stage actually shortens anything.

Input format

Source text. Anything you type. The end-of-word character $ is appended automatically if it is not already there, and it must occur exactly once, at the end — the whole section assumes it. A space is drawn as ␣. Type _ if that is easier; it is read as a space.

Inverse. The input box holds B instead, again containing exactly one $. Selecting any preset while in this view transforms it first and puts the resulting B in the box, so both views describe the same example.

Sizes. The matrix of cyclic shifts is n × n and every view here draws one row per character, so the Transform, Inverse and Why it is invertible views are limited to n = 80 and Why it compresses to n = 200. Chaining the transform with MTF and a coder, on texts of a few thousand characters, is a separate page.
