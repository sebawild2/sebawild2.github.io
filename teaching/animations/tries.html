Tries

A set of strings, drawn as a trie — one character per edge, so the strings sharing a prefix share a path — and as a compact trie, in which every path without a branch is contracted into a single edge. Each compact-trie node is labelled with the index of the next character to compare. An end-of-word marker $ is appended to every string, which makes the set prefix-free so that each string ends in its own leaf.

Input editor

Format. The words of the set, separated by whitespace or newlines. Use _ for a blank inside a word.

Every word silently gets an end-of-word marker $, so that no word is a prefix of another and every word ends in a leaf of its own.

The machine labels show what a program stores: one character per edge, and an index into the stored strings at each leaf. Nothing else is needed — all strings below an edge continue the same way, and the length of an edge label is the difference of the two node indices.
