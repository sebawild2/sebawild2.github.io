About this page — input format, conventions, open questions

Input. Only the pattern is needed. Σ defaults to the characters occurring in P; give it explicitly (e.g. abc) if the alphabet is larger than the set of pattern characters.

The idea. The table is filled column by column. Column j holds all transitions out of state j. On a mismatch in state j the automaton has to continue exactly as it would after reading P[1..j) — and the state for that is x, which is already known. So the whole column x is copied into column j (shaded), a single entry is overwritten by the match edge δ[j][P[j]] := j+1, and then x is advanced by feeding it P[j]. The strip on the left shows the invariant: P[1..j), the string that x stands for.

Colours. Green is the failure state x — the state, the column of the table it is copied from, and the edge it follows when it is updated; red is the state whose column is currently being built.

Cost. Every entry is written exactly once: Θ(mσ) time and Θ(mσ) space. The chips count the writes. Tick one step per copied entry to slow the copying down to single table cells.
