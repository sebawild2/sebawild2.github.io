Fat-Pivot Radix Quicksort

Three-way string quicksort: partition an array of strings by their dth character only, then recurse on smaller and larger with the same d and on equal with d+1 — so equal prefixes are never compared twice. Applied to all suffixes of a text, it computes the suffix array.
